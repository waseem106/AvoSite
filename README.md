# AvoSite

A React frontend project using Vite, Bootstrap and animation libraries.

## Technology

- React 18 and Vite 6
- Bootstrap and React Bootstrap
- React Router
- Framer Motion
- React Multi Carousel and Font Awesome

## Run locally

```bash
npm install
npm run dev
```

For a production build and local preview:

```bash
npm run build
npm run preview
```

## Deployment

This project includes a GitHub Pages deployment script: `npm run deploy`.

Configured deployment URL: https://waseem106.github.io/AvoSite (live availability not verified).
